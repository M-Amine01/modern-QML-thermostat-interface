# Temperature Control

A simple desktop temperature controller built with Qt, QML, and C++.

## Features

- Display current temperature
- Increase / decrease temperature
- Hot temperature preset
- Eco mode
- Cold temperature preset
- Temperature-based color indicator

## Requirements

- Qt 6
- Qt Quick
- Qt Quick Controls
- CMake
- A C++ compiler

## How to Build

1. Clone the repository:

```bash
git clone https://github.com/M-Amine01/modern-QML-thermostat-interface.git

```

2. Open the project with Qt Creator.
3. Configure the project with a Qt 6.8+ kit.
4. Build the project.
5. Run the application.
